
- **Goals**
    - Outcomes you want to achieve.


- **Projects**
    - Work organized around a specific objective.
    - Phases
        - Ordered stages within a project.
    - Files / artifacts
        - Project attachments and generated deliverables.


- **Tasks**
    - Project tasks — linked to a project, optionally grouped into a phase.
    - Standalone tasks — no project required.


- **Knowledge**
    - Notes
        - Freeform written information.
    - Links
        - Saved URLs with context or summaries.
    - Knowledge objects
        - Structured information with flexible object types and properties.
    - Memories
        - Thoughts
        - Memories
        - Decisions
        - Principles
        - Questions
        - Insights
        - Artifacts


- **People**
    - Contacts and information about individuals.


- **Companies**
    - Organizations and their details.


- **Calendar events**
    - Scheduled events and appointments.


- **Recurrences**
    - Repeating obligations.
    - Next due dates and completion history.


- **Quick captures**
    - Incoming text, URLs, and files awaiting processing.
    - Items temporarily held for transfer.


- **Financial records**
    - Accounts
    - Transactions
    - Daily balances
    - Budgets
    - Debts


- **Supporting information**
    - Relationships
        - Connections between records.
    - Source references
        - Where information came from.
    - Conversations
        - Chat sessions and messages.
    - Interviews and responses
        - Structured information gathered through questions.
    - User profile memories
        - Information about you and your preferences.
    - Operating rules
        - Instructions governing Skippy’s behavior.
    - Review and activity history
        - Decisions, changes, and actions taken.


- **Operational records**
    - Agent runs and execution events
    - Approvals and pending actions
    - Notifications
    - Ingestion and sync records
